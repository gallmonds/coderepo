A considerar:

  • -Angular por defect maneja el tag html asi que no tienes que preocuparte de agregarlo
  • -Te recomiendo usar divs para separar todo en contenedores, y darle ids o clases unicas. Por ejemplo, si tienes un contenedor para una seccion, poner un div, si tienes una seccion dentro de esa seccion, otro div
  • -Los footer, sidebars y navbars son recursos que se utilizan en todas las paginas del sistema menos en login (tal como en el mockup). No tienes que copiar todo el codigo del alguno de los elementos en todas las paginas, puedes reutilizar el codigo.
  • -En ningun momento vas a tener que tocar algun archivo css, si algo no se ve como pretendias, hay que modificar el tailwind
  • -Empieza desde el escritorio nomas, da igual si queda responsive o no
  • -Si estas corriendo el codigo desde docker, deberias poder ver tus cambios en vivo cada que guardas
  • -Si puedes hace un componente de error 404, yo me encargo que dirija alli cuando no encuentre pagina

Para poder empezar a hacer cambios debes:

  1. 1. Instalar nvm en este link.
  2. 2. Abrir una terminal (Normalmente con Windows+X y luego A)
  3. 3. Escribir 'nvm install latest'
  4. 4. Ir al directorio del proyecto que instalaste (si tienes dudas preguntame, pero te dejo una mini guia. Con ls puedes ver en que directorio estas ahora, con cd (nombre del directorio) puedes ir al directorio que nombraste, y con pwd puedes ver en que ruta estas)
  5. 5. Escribir 'npm i -g @angular/core'
  6. 6. Escribir 'npm i'

Para poder crear nuevas paginas debes:

  1. 1. Ir a /src/app/pages en tu terminal
  2. 2. Escribir 'ng generate component nombredetupagina'. Esto va a generar todos los archivos que necesitas.
  3. 3. Debes rutear tu componente para que aparezca en tu navegador como localhost:4200/nombredetucomponente
  4. 4. Para rutear, debes editar el archivo llamado 'app.routes.ts', que se encuentra en src/app/config
  5. 5. Debes agregar un nuevo import como los que ya estan, en este caso tienes que poner "import { NombreComponent } from '../pages/home/nombredetucomponente.component'"
  6. 6. Luego tienes que agregar una nueva ruta a la lista. En una nueva linea abajo de la que ya existe, tienes que poner "{ path: 'nombre', component: NombreComponent },"

Happy coding
